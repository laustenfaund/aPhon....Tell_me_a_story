# αPhon :: prompt_series

compressed narrative engines :: one line :: any model :: begin?

## what is this

Single-line prompts that initialize choose-your-own-adventure stories in large language models. Each prompt encodes genre, mood, protagonist, and dramatic tension into a compact sigil-like syntax.

Paste. Press enter. See what unfolds.

No setup. No system prompt. No configuration required.
